# Within- and Post-Expiry Spectral PCA, Photodegradation Kinetics, and Deconvolution Data

## Overview

This repository contains the raw and processed datasets generated during a study investigating the quality, stability, and photodegradation behavior of pharmaceutical cough syrup formulations using UV–Visible spectrophotometry and chemometric techniques.

The repository includes spectral datasets collected from within-expiry and post-expiry samples, together with data used for Principal Component Analysis (PCA), photodegradation kinetic modeling, and spectral deconvolution studies.

## Objectives

The data were generated to:

- Evaluate spectral differences between within-expiry and post-expiry pharmaceutical samples.
- Investigate photodegradation behavior under controlled conditions.
- Model degradation kinetics using spectroscopic data.
- Perform spectral deconvolution of overlapping UV–Visible absorption bands.
- Assess the applicability of chemometric approaches for pharmaceutical quality evaluation.
